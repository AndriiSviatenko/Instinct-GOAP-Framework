# Farmer sample

Open `FarmerGoap.unity` and enter Play Mode.

This sample demonstrates the high-level Flow API: fact bindings, self-executing async action classes, automatic effect mirroring, cancellation during replanning, `GoapBrain`, and a minimal MonoBehaviour host.

The sample requires UniTask, which the package manifest installs from its official Git repository. The scene uses TextMesh Pro for labels and is render-pipeline agnostic.
